Зарегистрированные волонтёрские часы на dobro.ru

Поиск организации по названию и извлечение блока «Часы» из карточки (вкладка «Информация» → «Рейтинг» / «Результаты» / «Часы»). Данные: публичный API dobro.ru.

API: GET /api/hours?q=... · GET /api/total?region=72&year=2025
Источник данных: открытые эндпоинты dobro.ru (/api/v2/organizers/search, /api/v2/organizations/:id, /api/v2/analytics/get). Число часов — «Количество зарегистрированных часов на портале» из карточки организации. Значения на портале обновляются постоянно, поэтому цифры могут отличаться от снимка.
